# piDesk — Descargas

piDesk es una aplicación de escritorio para programación asistida por IA.
Da sitio fijo a cada proyecto y mantiene el contexto entre sesiones.
Todo local, cero telemetría, cero cuenta.

## Descargar

Andá a la sección [Releases](https://github.com/itek-ar/pidesk-releases/releases/latest)
y elegí el instalador para tu sistema:

- **Windows**: `piDesk-x.x.x-x64.exe`
- **Linux (AppImage)**: `piDesk-x.x.x-x86_64.AppImage` (no requiere instalación)
- **Linux (Debian/Ubuntu)**: `piDesk-x.x.x-amd64.deb`

## Uso

El programa base es gratuito y de uso libre. Ver el archivo
